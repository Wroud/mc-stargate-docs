# mc-stargate-docs

Public assets for the [Stargate](https://modrinth.com/mod/mc-stargate) mod's store pages on Modrinth and CurseForge. The page text is `LISTING.md` in the private `mc-stargate` repo; the images live here because raw.githubusercontent.com only serves public repos.

`listing/` holds the banner, the Pixly promo strip, the badges, the section ribbons and the screenshots, linked as `https://raw.githubusercontent.com/Wroud/mc-stargate-docs/main/listing/<file>`. They are rendered with the `mod-listing` skill from `mc-mod-skills`; re-render, commit and push here before publishing a listing change.
